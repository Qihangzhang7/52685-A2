# Recreating Mo Li Hua in TunePad

## Project Overview

This project implements the traditional Chinese folk song *Mo Li Hua* with Python on TunePad. It contains two voices: the main melody on Crystal Organ and a Musicbox accompaniment. I built the piece using `playNote()`, lists, loops and variables, and refined note spacing for smoother playback.

## How to Run

1. Open the [TunePad project](https://tunepad.com/project/135120)
2. Enable both tracks
3. Reset playback to the start
4. Press Play

Mute a track to listen to a single voice. The code runs directly in TunePad, so no local Python installation is required.
